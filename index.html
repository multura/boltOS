Начать »

💻 Unix-подобная среда

Полноценный shell с командами, файловой системой и управлением процессами

📦 Пакетный менеджер APK

Установка, удаление и управление пакетами через APK-подобный менеджер

🎮 CLI игры

Змейка, крестики-нолики, угадай число и виселица прямо в терминале

Встроенный редактор с подсветкой и горячими клавишами

🔧 Утилиты

htop, neofetch, figlet, cowsay и другие системные утилиты

🎨 Gruvbox тема

Красивая цветовая схема для терминала и интерфейса

Установка и запуск

git clone https://github.com/your-repo/boltOS.git
cd boltOS
php boltos.php

После запуска вы попадете в Matter shell с приветствием:

root@boltos:~ λ

Основные команды APK

  • apk add [пакет] - Установить пакет
  • apk del [пакет] - Удалить пакет
  • apk reinstall [пакет] - Переустановить пакет
  • apk list - Список пакетов
  • apk search [запрос] - Поиск пакетов

Файловые команды

  • ls - Список файлов
  • cd [путь] - Сменить директорию
  • cat [файл] - Просмотр файла
  • vie [файл] - Редактировать файл
  • mkdir [папка] - Создать папку
  • rm [файл] - Удалить файл

Системные команды

  • neofetch - Информация о системе
  • htop - Мониторинг процессов
  • ps - Список процессов
  • df - Использование диска
  • free - Использование памяти

Игры

  • snake - Классическая змейка
  • tictactoe - Крестики-нолики
  • guess - Угадай число
  • hangman - Виселица

Примеры использования

Установка пакета:

apk add neofetch
neofetch

Работа с файлами:

mkdir test
cd test
touch hello.txt
vie hello.txt
cat hello.txt

Запуск игры:

snake
