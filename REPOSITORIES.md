# Управление репозиториями в boltOS

boltOS поддерживает несколько репозиториев пакетов, что позволяет использовать как официальные, так и собственные репозитории.

## Конфигурация репозиториев

Конфигурация репозиториев хранится в файле `storage/repositories.json`:

```json
{
    "repositories": [
        {
            "name": "official",
            "url": "https://content.uzbekistation.serv00.net/boltos/repository",
            "enabled": true
        }
    ]
}
```

## Команды управления

### Список репозиториев

```bash
apk repo list
```

Выводит список всех настроенных репозиториев с их статусом (включен/отключен).

### Добавление репозитория

```bash
apk repo add <имя> <url>
```

Добавляет новый репозиторий в конфигурацию.

Пример:
```bash
apk repo add myrepo https://example.com/repo
```

### Удаление репозитория

```bash
apk repo remove <имя>
```

Удаляет репозиторий из конфигурации.

Пример:
```bash
apk repo remove myrepo
```

### Включение репозитория

```bash
apk repo enable <имя>
```

Включает указанный репозиторий. Пакеты из этого репозитория будут использоваться при установке.

Пример:
```bash
apk repo enable myrepo
```

### Отключение репозитория

```bash
apk repo disable <имя>
```

Отключает указанный репозиторий. Пакеты из этого репозитория не будут использоваться.

Пример:
```bash
apk repo disable official
```

## Логика работы

1. **Загрузка метаданных**: При выполнении `apk update` система загружает `packages.json` из всех включенных репозиториев.
2. **Объединение пакетов**: Пакеты из разных репозиториев объединяются. Если пакет с одним именем существует в нескольких репозиториях, используется версия из репозитория, который был добавлен последним.
3. **Поиск пакета**: При установке пакета система ищет его во всех включенных репозиториях по очереди.

## Настройка собственного репозитория

Для создания собственного репозитория:

1. Разместите `packages.json` и `.tar.gz` файлы на вашем сервере
2. Структура репозитория:
   ```
   https://example.com/repo/
   ├── packages.json
   ├── busybox.tar.gz
   ├── curl.tar.gz
   └── ...
   ```
3. Добавьте репозиторий в boltOS:
   ```bash
   apk repo add myrepo https://example.com/repo
   apk update
   ```

## Примеры использования

### Использование только локальных пакетов

```bash
apk repo disable official
apk update
```

### Добавление тестового репозитория

```bash
apk repo add test https://test.example.com/repo
apk update
```

### Временное отключение официального репозитория

```bash
apk repo disable official
# Работаем с локальными пакетами
apk repo enable official
apk update
```

## Формат packages.json

Файл `packages.json` должен содержать метаданные всех пакетов в репозитории:

```json
{
    "busybox": {
        "name": "busybox",
        "version": "1.0.0-r0",
        "description": "Набор базовых утилит",
        "size": 1024,
        "dependencies": [],
        "provides": ["sh", "ls", "cat", "cp", "mv", "rm", "mkdir"]
    },
    "curl": {
        "name": "curl",
        "version": "7.80.0-r0",
        "description": "Утилита для загрузки файлов",
        "size": 512,
        "dependencies": ["busybox"],
        "provides": ["curl"]
    }
}
```

## Устранение проблем

### Репозиторий недоступен

Если репозиторий недоступен, система автоматически перейдет к следующему репозиторию в списке. Убедитесь, что хотя бы один репозиторий доступен.

### Пакет не найден

Если пакет не найден ни в одном из репозиториев, убедитесь что:
- Репозитории включены (`apk repo list`)
- Индекс пакетов обновлен (`apk update`)
- Пакет существует в одном из репозиториев

### Конфликт версий пакетов

Если пакет с одним именем существует в нескольких репозиториях, используется версия из репозитория, который был добавлен последним. Чтобы контролировать приоритет, добавляйте репозитории в нужном порядке.

### Ошибка "Конфигурация репозиториев не найдена"

Если файл `storage/repositories.json` отсутствует или поврежден, система автоматически создаст его с официальным репозиторием.
